# Security

## Report a problem

Use GitHub's private vulnerability report for security problems. Do not put
secrets, private prompts, or customer data in a public issue.

Use a public issue for normal bugs that contain no private data.

## Safe use

Regression Test does not include a remote service. Promptfoo may call the model
provider you configure. Keep secrets in environment variables. Do not store them
in prompts, golden cases, result files, or source control.
